# DragAndDrop
В данном проекте реализованы две механики на каждую из которой был создан свой собственный скрипт.
В папке Assets/Scripts находятся два файла:
 DragAndDrop.cs. В нем реализована основная механика поднятия перетаскивания и опускания предметов, на которые выделены три основных метода
 CameraScroll.cs. В нем реализована прокрутка изображения сцены
В качестве ассетов для данного проекта были выбраны спрайты заднего фона (ссылка на него прилагалась в тестовом задании) и перетаскиваемого предмета (я выбрал станок для бритья).
Также для того, чтобы предмет лежат на полке, в местах, где в спрайте заднего фона она была нарисована я добавил Box Collider 2D.
